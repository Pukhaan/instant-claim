# Changelog

- **Hour 1–3: Claude tool-use agent loop + streaming chat UI.** New files: `api/app/tool_defs.py` (6 typed tool schemas mapped 1:1 to `bunq_service` functions — `whoami`, `list_accounts`, `list_transactions`, `create_sub_account`, `move_money`, `request_sandbox_money`), `api/app/agent.py` (TellerAgent class that runs a Claude tool-use loop server-side and yields `text_delta` / `tool_use` / `tool_result` / `tool_error` / `done` / `error` events), `api/app/routes/chat.py` (`POST /chat` SSE endpoint + `POST /chat/reset`, in-memory session store keyed by client-chosen `session_id`), `web/lib/chat.ts` (async-iterator client helper that parses SSE lines), `web/app/chat/page.tsx` + `web/app/chat/chat-view.tsx` (streaming chat UI with starter prompts, tool-call bubbles that expand to show input/output JSON, `▍` pulse while streaming, clear button, keyboard-first composer). Problem solved: the agent-native experience the hackathon actually rewards — one place where the user talks and the bank acts, with every tool call visible and every mutation going through Claude's explicit-confirmation prompt rule.
