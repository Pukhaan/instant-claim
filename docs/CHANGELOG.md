# Changelog

## 24-04-2026

- **Demo 1 — voice input + card-based AI responses + chat-first landing.** Backend: new `api/app/transcribe.py` wires AWS Transcribe end-to-end — auto-provisions a regional S3 bucket (`teller-audio-<account>-<region>`) with a 7-day lifecycle rule, uploads the posted audio blob, starts a batch transcription job with auto language detection, polls until done (≤ 60 s), fetches the transcript JSON, returns `{text, language, confidence, duration_s, job_name}`. Supports webm/opus, ogg, mp4, m4a, mp3, wav, flac. New route `POST /transcribe` in [`api/app/routes/voice.py`](api/app/routes/voice.py) with a 8 MB cap. Smoke-tested live: a 5.7 s macOS-`say` clip of "I just got a €500 bonus..." transcribed in ~11 s with confidence 0.799, language `en-US`, even auto-formatting "500 euro" → "€500". Updated [`api/app/agent.py`](api/app/agent.py) `SYSTEM_PROMPT` so Claude emits replies in structured `## TL;DR`, `## Steps`, `## Why`, `## Next` sections (never more than 3, with an explicit override to skip headings for simple acknowledgements). Frontend: new [`web/lib/parse-cards.ts`](web/lib/parse-cards.ts) (streaming-safe parser that splits assistant text on `## SectionName` into labelled cards) + [`web/app/chat/assistant-message.tsx`](web/app/chat/assistant-message.tsx) (renders each card as a bordered tile with an uppercase orange label, with bullet auto-detection and `tabular-nums` throughout). New [`web/lib/voice.ts`](web/lib/voice.ts) with a `createRecorder()` wrapper around `MediaRecorder` (prefers opus/webm, falls back to mp4 on Safari) and a `transcribeBlob()` helper that posts the audio to `/api/transcribe` as multipart. [`web/app/chat/chat-view.tsx`](web/app/chat/chat-view.tsx) rebuilt: added a mic button to the composer (tap to start, tap to stop, transcribing/error states; placeholder swaps to "Listening…" and "Transcribing…"), auto-sends the transcript as a user message, uses `AssistantMessage` component for all assistant replies, keeps the AI_Logo avatar next to each assistant response. New `[hero]` variant of the starters shows a big 64px AI_Logo with "Hi, I'm Teller." greeting when the conversation is empty. Chat-first landing: [`web/app/page.tsx`](web/app/page.tsx) now renders `ChatView hero`, the old dashboard moved to [`web/app/dashboard/page.tsx`](web/app/dashboard/page.tsx), nav updated to `Chat · Dashboard · Receipts · Sandbox`. `/chat` still works as a deep-link alias. Problem solved: voice-first demo path ("push mic → say anything → Teller acts and replies in structured cards") is now the app's primary surface, matching how the Demo 1 pitch is meant to land.
